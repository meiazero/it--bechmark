# it++-bechmark

A reproducible point-to-point OFDM simulator written four times: a C++/IT++ reference and
idiomatic Python/NumPy, Rust, and Julia versions. All four implement the same signal chain
under one frozen numerical contract, so performance, correctness, memory, scaling, and
ergonomics can be compared separately. The code doubles as material for a lecture on
optimization and telecommunications.

- Chain: bits → Gray 16-QAM → subcarrier grid with pilots → IFFT → cyclic prefix → Rayleigh
  multipath + AWGN → FFT → LS estimation with linear interpolation → ZF → hard decisions.
- Frozen profile: `N=256`, `N_cp=32`, 168 data and 24 pilot subcarriers, 8 channel taps,
  256 OFDM symbols per batch ([contract/profile_main.json](contract/profile_main.json)).
- Each implementation must reproduce 11 golden cases generated by a stdlib-only Python oracle.
- Status: milestones M0–M8 are done. Comparison measurements (M9) and the final report (M10)
  are deferred; the interrupted M9 run under `results/` is not a valid comparison.

## Install

Pinned toolchain through mise, pinned C++ libraries through apt (Ubuntu 24.04 package
versions):

```bash
mise install
sudo apt install g++ libitpp-dev=4.3.1-10build1 libfftw3-dev=3.3.10-1ubuntu3 \
  nlohmann-json3-dev=3.11.3-1
eval "$(mise env -s bash)"   # required in non-interactive shells before any make target
make doctor                  # fails if any tool or package version differs from the pin
```

## Quick start

```bash
make check     # build all four implementations, run contract and golden checks
build/cpp/ofdm --config contract/profile_main.json --mode golden --workers 1 --out /tmp/cpp.jsonl
python tools/check_golden.py --config contract/profile_main.json --workers 1 --actual /tmp/cpp.jsonl
make bench-plan TURBO=on   # print the planned benchmark commands without running them
```

The other simulators take the same CLI: `impl/python/.venv/bin/python impl/python/src/ofdm.py`,
`build/rust/release/ofdm-rust`, and
`julia --startup-file=no --project=impl/julia impl/julia/src/main.jl`.
Modes are `golden`, `ber`, `perf`, and `stages`; exit code 2 means an invalid configuration.

## Development

```bash
make golden    # regenerate golden vectors and theory curves, self-test the verifier
make check     # code-only checks; collects no benchmark measurements
make test      # all tests, including a smoke benchmark collection
```

- `contract/` is the source of truth; never edit its values to make an implementation pass.
- `tools/golden/` imports only the Python standard library and never a competing implementation.
- Rules for coding agents live in [CLAUDE.md](CLAUDE.md).
